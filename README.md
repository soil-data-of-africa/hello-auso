# A prototype for the African Union Soil Oberservatory

Based on wireframes provided by Cabi.

You can view the observatory online at https://soil-data-of-africa.github.io/hello-auso/

The website is developed as a [quarto website](https://quarto.org/docs/websites/)

We invite you to report [issues](https://github.com/soil-data-of-africa/hello-auso/issues) or participate in [discussions](https://github.com/soil-data-of-africa/hello-auso/discussions).
