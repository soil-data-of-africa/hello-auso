Between 2022 and 2024 a campaign has run which has observed and sampled a large number of sites across Africa.
At this page the data acquired in this campaign can be downloaded. Read more about the campaign at [Soils for Africa](https://www.soils4africa-h2020.eu/).

## Field observations and samples

At each site a number of properties have been observed and samples have been analysed in the lab. The data can be downloaded as CSV or Geopackage.

- Texture (top layer [CSV](#)/[GeoPackage](#) / deeper layer [CSV](#)/[GeoPackage](#))
- Bulk density (top layer [CSV](#)/[GeoPackage](#) / deeper layer [CSV](#)/[GeoPackage](#))
- Organic Carbon Content (top layer [CSV](#)/[GeoPackage](#) / deeper layer [CSV](#)/[GeoPackage](#))
- Chemical properties (top layer [CSV](#)/[GeoPackage](#) / deeper layer [CSV](#)/[GeoPackage](#))

## Soil Maps

Soil maps are grid files representing the distribution of soil properties. The soil maps have been derived from observation data, using spatial statistics and machine learning models, using relevant co-variant stacks. Grids are available in a [GeoTIFF](https://en.wikipedia.org/wiki/GeoTIFF) format and can be opened in for example [QGIS](https://qgis.org). For each pixel, an estimation of the accuracy is available.
